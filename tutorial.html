HELP CENTER / GETTING STARTED

Learn FinSight AI, step by step.

A starter guide for the core workflow. Screens and features may vary by release; update this guide to match the production version before publishing.

01

Open your workspace

Install the verified release or open the hosted application using the official link supplied by Vikora. Create your account and sign in. Never share your password or authentication codes.

  • Use a unique, strong password.
  • Confirm you are on the official Vikora domain before entering credentials.
02

Import transaction data

Open the import/upload area and select a supported file. Check the required column names and date/amount format first. Begin with a small sample and verify the imported records.

  • Keep a secure original copy of your records.
  • Do not upload data you are not authorized to share.
03

Review AI category suggestions

Inspect each suggested category and any confidence or review status shown. AI suggestions can be wrong; correct categories and approve records only after checking the source information.

04

Read the dashboard and reports

Use the dashboard to review income, expenses and profit. Choose the reporting period that matches your question, then reconcile totals against your source records before using them for filing or business decisions.

05

Get help

If a file fails to import or a figure looks incorrect, record the error message and contact support. Remove account numbers and other sensitive financial details before sending screenshots or logs.
