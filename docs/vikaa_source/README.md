# Approved Vikora-One source documentation

Add approved, non-confidential Vikora-One manuals, release notes, module instructions, troubleshooting guides, and installation documentation in this folder. Supported ingestion formats are PDF with selectable text, Markdown, and plain text. For screenshots, add a Markdown caption file describing the screen and verified steps; images are not OCR-processed automatically. Do not add customer data, credentials, licence secrets, or confidential screenshots.
