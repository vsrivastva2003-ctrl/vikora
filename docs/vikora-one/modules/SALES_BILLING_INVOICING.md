# Module Guide — Sales, Billing, and Invoicing

**Status:** Generic workflow draft; verify against actual Vikora-One screens before publication as an authoritative procedure.

## Purpose

Use the approved sales workflow to create and track customer-facing documents while avoiding duplicates and incorrect stock/account effects.

## Procedure checklist

1. Confirm company/branch, customer, period, and user permissions.
2. Search for an existing quotation/order/invoice before creating a new record.
3. Select the correct document type; do not treat order, delivery, invoice, and receipt as equivalent.
4. Enter customer, date, reference, items/services, quantities, units, rates, authorised discounts, and approved tax details.
5. Review totals, payment terms, due date, and source-document references.
6. Save/submit using the action documented for the installed edition.
7. Reopen the record and verify its number, status, and totals.
8. Check stock, receivables, and reports only as described in the customer's verified configuration.

## Common symptoms

- **Wrong total:** Recheck quantity, unit, rate, discount permissions, tax configuration, rounding, and document status.
- **Duplicate invoice risk:** Search by customer, external invoice number, date, and amount before retrying.
- **Invoice missing from report:** Match company/branch, date range, status/posting filters, and report scope.
- **Stock/account balance did not change:** Confirm whether the document type and status trigger those updates in this edition.
