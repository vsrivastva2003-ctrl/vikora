# Installation, Licence Activation, and Multi-User Setup

**Status:** Safety-first general checklist. It is not a substitute for the official installer guide or licence terms.

## Before installation or upgrade

- Confirm Vikora-One edition/version and supported operating system.
- Verify the official installation source, system requirements, database requirements, licence entitlement, and authorised administrator.
- Make and verify a backup using the documented method; test restore on a safe environment where possible.
- Read release notes and the supported upgrade path.
- Avoid running unknown commands or scripts on production systems.

## Licence activation

1. Use the official licence/activation instructions for the exact edition.
2. Verify the registered installation/server, licence status, expiry, and permitted user count through the authorised administration process.
3. Never paste a secret licence key into public tickets or chat.
4. If activation fails, record the exact non-secret error and contact Vikora support. Do not bypass licence checks.

## Client/server connectivity

1. Determine whether one client or all clients are affected.
2. Confirm server power and approved application services; do not restart production services without authorisation.
3. Verify the client is on the approved LAN/Wi-Fi or VPN.
4. Ask IT to verify configured hostname/IP and name resolution.
5. Test reachability if permitted; note that ping may be blocked.
6. Have IT check only the documented application service/port and firewall rules.
7. Never disable firewalls, expose database ports to the internet, or guess service ports.
