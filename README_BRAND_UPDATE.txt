- images/favicon.svg: compact browser tab icon.

INSTALLATION
1. Upload/replace index.html, styles.css and script.js in the existing GitHub repository.
2. Upload the three SVG files into the existing images/ folder (do not delete the other images already used by the site).
3. Commit the changes to the deployment branch. If Render auto-deploy is enabled, wait for the new deployment to finish.
4. Hard-refresh the site (Ctrl+F5). Favicons can be cached by the browser; if the old icon remains, close/reopen the tab or clear site cache.

The checkout interface still requires a real payment provider and secure backend before accepting payments or issuing licenses.
